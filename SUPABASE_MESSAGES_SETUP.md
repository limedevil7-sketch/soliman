# Shared Messages setup

The Messages page is Supabase-ready. To make messages truly shared and realtime, add your Supabase project URL and public anon/publishable key to `js/messages-config.js`.

Run this SQL in Supabase:

```sql
create table if not exists public.messages (
  id bigint generated by default as identity primary key,
  content text not null check (char_length(content) between 2 and 280),
  author_name text not null default 'شبح' check (author_name = 'شبح'),
  avatar text not null default '👻',
  created_at timestamptz not null default now()
);

alter table public.messages enable row level security;

create policy "public can read messages"
on public.messages for select to anon using (true);

create policy "public can insert messages"
on public.messages for insert to anon
with check (author_name = 'شبح' and avatar = '👻' and char_length(content) between 2 and 280);
```

Enable Realtime for `public.messages`.

Never put a Supabase service-role key in the frontend.
